# Routes

## `/supplier_finder.html`
- Entry: `supplier_finder.html`
- Layout: standalone Supplier Finder shell.
- Purpose: procurement workspace for filtering, reviewing, selecting, and exporting suppliers.
- Main regions: request summary, KPI counts, filters, confirmed suppliers, possible suppliers, export dialog.

## Removed route
- `/dashboard.html` no longer exists and intentionally returns `404`.

## Router
No client-side router. The project is served as static HTML by the local server.
