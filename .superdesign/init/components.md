# Component inventory

## Architecture
- Framework: none; standalone HTML document with vanilla JavaScript.
- Component library: none; visual primitives are CSS classes in `supplier_finder.html`.
- CSS approach: embedded vanilla CSS tokens and component selectors.
- Data/rendering: inline `DATA` object plus render functions in the same file.

## Shared components

There is no separate shared component directory. The following reusable patterns are embedded in `supplier_finder.html` and are candidates for extraction:

### Button
Source: `supplier_finder.html`
Variants: `.btn`, `.btn.primary`, `.btn.ghost`, `.btn.stop`
States: default, hover, active, disabled, focus-visible.

### SupplierCard
Source: `supplier_finder.html`, generated by `cardHtml(s)`
Props represented by data: host, title, tags, confidence, coverage, contacts, risks, selected state.

### FilterBar
Source: `supplier_finder.html`, `.controls`
Controls: region, kind, role, text search, select-all, export.

### ExportDialog
Source: `supplier_finder.html`, `#sheet`
Role: dialog; contains a generated table of selected contacts.
