# Рабочее пространство «Сообщения»

## Цель

Экран `/messages` связывает три сущности в одном рабочем контексте:
заявку, поставщика и переписку. Основной режим — двухколоночный список
заявок/поставщиков слева и выбранная переписка справа; на узком экране список
и переписка открываются последовательно.

## Рабочий сценарий

- Заявки группируют переписки. Группа с непрочитанным ответом, незавершённой
  отправкой или неопределённой доставкой раскрывается автоматически.
- Поиск работает по заявке, поставщику, теме, адресу и домену. Во время
  поиска совпадения внутри свёрнутых групп становятся видимыми.
- Вверху списка показываются до трёх последних писем без привязки. Кнопка
  «Связать» и раздел «Показать все» используют существующий ручной workflow.
- Письмо без привязки можно перетащить на заголовок заявки как короткий путь.
  Автоматическая связь выполняется только для единственного точного
  совпадения отправителя. Совпадение только по домену, несколько совпадений
  или отсутствие совпадения открывают ручной выбор и не угадывают поставщика.
- Название поставщика в строке сокращает юридическую форму только для показа;
  полное название доступно в подсказке и в деталях. Префикс «ИП» сохраняется.

## Метаданные закупщика

Флаг «Важное» и приоритет 1/2/3 — независимые личные метаданные закупщика.
Они хранятся отдельно от статуса отправки, ответа и доставки, привязаны к
пользователю, рабочему пространству, заявке и поставщику и сохраняются после
перезагрузки. Изменение сначала показывается в интерфейсе, а при ошибке API
возвращается к предыдущему значению.

## Границы

Экран не добавляет AI/OCR, автоматический скоринг, цены, логистику,
сравнительную панель, закупку, новый третий сайдбар или глобальный редизайн.
Почтовая очередь, статусы доставки, безопасная отправка и ручная привязка
остаются существующими механизмами.
