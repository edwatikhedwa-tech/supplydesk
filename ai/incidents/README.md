# Incident records

This directory contains structured incident records only when a verified
failure needs durable investigation. V1 creates no incident record. Use
[`INCIDENT_SCHEMA.yaml`](INCIDENT_SCHEMA.yaml), never an ad-hoc private note;
do not copy secret values, tokens, cookies or mailbox contents into an
incident.
