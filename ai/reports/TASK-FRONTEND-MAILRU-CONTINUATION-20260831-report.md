## Простыми словами

Ответ поставщику теперь открывается сразу в поле ввода и управляется с
клавиатуры/скринридера. Страница грузит меньше стартового JavaScript, а
статические файлы быстрее повторно открываются. Для почты выбран только
неповторный остаток; уже принятые и сомнительные адреса в повторную отправку
не включаются.

## Риски

Любая фактическая отправка — внешнее действие и может быть необратимой. Поэтому
перед стартом нужен action-time confirmation точного списка из двух адресов.
После отправки нужно проверить SMTP-код/провайдерный идентификатор, статусы
сообщений и отсутствие второй попытки.

## Откат

Код откатывается коммитом `568391d` через обычный git revert при отдельном
решении владельца. Почтовую отправку нельзя надёжно «отозвать» после принятия
Mail.ru; до отправки безопасный откат — ничего не менять, outgoing остаётся
выключенным.
