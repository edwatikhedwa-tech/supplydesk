# Матрица источников поставщиков

Дата smoke-прогона: 2026-08-28
Тестовая фраза: `кабель ВВГнг 3х2.5`

Это техническая проверка доступности поиска и публичных контактов, а не
проверка добросовестности компаний. Контактом для заявки считается только
номер/email из карточки, которая одновременно относится к товару и продавцу.
Телефоны из заявок «купим»/«ищу» не считаются.

## Что означает результат

На тестовом ключе реально пригодный прямой контакт автоматически получен из
Flagma после перехода в карточку товара. Остальные полезные источники пока
дают либо релевантную товарную выдачу без контакта в HTML, либо требуют
карточного обхода, входа, платного открытия контакта, POST/JS-маршрута или
разрешённого API.

Для production-пайплайна контакт нужно сохранять вместе с URL карточки,
названием компании, городом, товарным совпадением и признаком `seller`, а
заявки покупателей маркировать отдельно и не отправлять в лиды поставщиков.
