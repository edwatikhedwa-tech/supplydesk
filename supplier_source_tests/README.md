# Тест источников поставщиков

Изолированный read-only стенд для проверки, из каких каталогов можно получить
релевантных поставщиков и пригодные для заявки контакты.

## Что проверяется

Тестовая поисковая фраза:

```text
кабель ВВГнг 3х2.5
```

В этом стенде слово «ключ» означает поисковую фразу. Доступ XMLRiver берётся
только из локального `.env` проекта и никогда не записывается в отчёт, URL
результата или файлы теста.

Прогон выполняет:

1. один запрос к XMLRiver/Яндексу и сопоставляет найденные домены с матрицей;
2. один публичный JSON-RPC вызов `searchProducts` к Tonzar MCP;
3. read-only проверку главной страницы и обнаруженных GET-форм поиска у
   каталогов;
4. для части каталогов — до трёх публичных карточек товара, чтобы проверить,
   есть ли контакт именно продавца, а не только совпадение товара в выдаче.
   Заявки покупателей («купим», «ищу», «требуется») отбрасываются.

POST-формы, вход, «Показать контакты», отправка заявок и любые внешние
изменения не выполняются.

## Запуск

Из корня проекта:

```powershell
python .\supplier_source_tests\run_probe.py
```

Только локальная проверка без сети:

```powershell
python .\supplier_source_tests\run_probe.py --dry-run
```

Результаты сохраняются в `supplier_source_tests/out/`. JSON-отчёт не содержит
секретов; в репозитории не должны появиться ключи, cookies, пароли или токены.

## Интерпретация

- `direct` — в публичной карточке/выдаче есть данные для прямого контакта;
- `partial` — товар и компания находятся, но контакт скрыт, замаскирован или
  требует входа/оплаты;
- `fallback` — полезен для обогащения уже найденной компании, но слабее как
  источник релевантного поставщика по товарному ключу;
- `structured` — есть заявленный структурированный интерфейс, который можно
  интегрировать без парсинга HTML;
- `not_confirmed` — возможность не подтверждена текущим read-only прогоном.

Результат не является проверкой юридической добросовестности поставщика. Перед
отправкой заявки контакты нужно дополнительно связать с доменом/ИНН и проверить
по существующему pipeline проекта.
